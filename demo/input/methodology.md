# Methodology — Demo Report (Synthetic)

> Fully synthetic demo methodology for the Northwind Traders demo dataset.

## Data Sources

- Market sizing: fictional "European Coffee Retail Review 2025" (demo source).
- Consumer trends: fictional "Urban Coffee Consumer Survey 2025" (demo source).
- Competitor data: fictional "DACH Specialty Coffee Competitor Tracker" (demo source).

All sources in this demo are fictional. In a real project, replace them with
verified public sources or licensed market research.

## Rules for the Report

1. Use only figures present in market_data.md. Do not extrapolate beyond them.
2. Derived calculations must be explicitly labeled as calculations.
3. If data is missing for a question, write "Data not available" instead of guessing.
4. Keep the report factual, concise and structured for a C-level audience.

## Quality Criteria

- Every key question from the company brief must be addressed.
- Every numeric claim must be traceable to a source in market_data.md.
- No unsupported forecasts.
