# Methodology

## Tone of Voice

- Профессиональный, data-driven, но доступный.
- Без излишней академичности и маркетинговых клише.
- Прямая формулировка выводов с опорой на факты.

## Report Structure

Отчёт собирается строго в следующем порядке секций:

1. **Executive Summary** — ключевые выводы и рекомендации (0.5–1 страница).
2. **Market Overview** — размер рынка, сегменты, прогнозы.
3. **Competitive Landscape** — основные игроки, их позиции и сильные стороны.
4. **Key Risks** — регуляторные, культурные, конкурентные, инфраструктурные.
5. **Recommendations** — практические шаги по входу на рынок.

## Factuality Requirements

- **Все цифры в отчёте должны быть взяты исключительно из `market_data.md`.**
- Запрещается добавлять цифры, которых нет в исходных данных.
- Если по вопросу данных нет в `market_data.md` — использовать явную пометку **"Data not available"** вместо любых догадок.
- Названия компаний, стран и продуктов приводятся только так, как они указаны в исходных данных.

## Hallucination Policy

- Не допускается выдумывание статистики, названий, дат и источников.
- Все утверждения должны прослеживаться до конкретной строки исходных данных.
- При противоречиях между источниками приоритет у `market_data.md`.

## Output Requirements

- Финальный отчёт: markdown-файл 5–7 страниц.
- Каждая секция отчёта должна соответствовать структуре выше.
- Отчёт должен быть готов к конвертации в DOCX.
